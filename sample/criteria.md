# 평가 기준

> 고등학생들이 배우면서 푸는 문제이므로 점수는 후하게 준다.<br/>
> 입력과 출력이 있어야 하는 경우 입력받지 않고 출력만 모범답안과 같이 하는 경우 점수를 주지 않는다.<br/>
> 각 평가 요소 별 만족하는 항목 수마다 배점이 다르다.<br/>
> 특이사항은 별도 평가 요소 아래에 작성한다. <br/>
> 꼭 실행시켜보고 채점한다.

## 평가 요소: 함수 설계 및 구현
> 특이사항: 문제 1번에서 함수를 선언/호출할 수 있으면 2~3번에서는 선언/호출이 틀려도 점수 줌

| 만족 항목 수 | 배점 |
|---------|----|
| 0       | 2  |
| 1       | 4  |
| 2       | 6  |
| 3       | 8  |
| 4       | 10 |

### 문제 1

- 문제 상황에 적합한 함수를 정의(선언)할 수 있음
- 정의한 함수를 호출할수 있음

### 문제 2

- 매개변수와 인자의 차이를 이해하고 활용할 수 있음

### 문제 3

- 반환값의 개념을 이해하고 활용할 수 있음
