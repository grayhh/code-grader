  • 식이 r**2 가 아니라 r**r 로 작성됨

학생 코드

    a = 3.14 * r ** r
    return a

r = float(input())
print(circle())

    result = 3.14 * r ** 2
    return result

r = float(input())
area = circle()
print(area)
