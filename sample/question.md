### 문제 7

> 10번째 피보나치 수열 값을 계산하는 Fibo 함수를 선언하고 호출하세요.

- 함수 기능
    - 재귀 형식을 사용하여 전달 받은 수의 피보나치 수열 값을 계산한다.

- 메인 기능
    - 피보나치 함수를 호출하며 10을 전달한다.
    - 10번째 피보나치 수열 값을 출력한다.
- 테스트케이스

  | Input | Print |
                  |-------|-------|
  |  | 55    |

```help
피보나치 수열이란?

- 정의: F1 = 1, F2 = 1, Fn=Fn-1 + Fn-2

1, 1, 2, 3, 5, 8, 13......

1번째 피보나치 수열 : 1

2번째 피보나치 수열 : 1

3번째 피보나치 수열 : 2 = 1+1

4번째 피보나치 수열 : 3 = 2+1

5번째 피보나치 수열 : 5 = 2+3

*참고 : 0번째 피보나치 값은 0 입니다.
```
