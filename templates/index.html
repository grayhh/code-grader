# 평가 기준

> 후하게 채점한다 등
> 전반적인 채점 정책을 적습니다.

## 평가 요소: 함수 설계 및 구현
> 특이사항: 문제 1 통과 시
> 2~3은 관대하게

| 만족 항목 수 | 배점 |
|---------|----|
| 0       | 2  |
| 1       | 4  |
| 2       | 6  |
| 3       | 8  |

### 문제 1
- 함수를 정의(선언)할 수 있음
- 정의한 함수를 호출할 수 있음

### 문제 2
- 매개변수와 인자를 활용할 수 있음

## 평가 요소: 변수 활용
| 만족 항목 수 | 배점 |
| ...
✓ 꼭 지킬 것
  • 평가요소는 ## 평가 요소: 이름 형식
  • 평가요소마다 | 만족 항목 수 | 배점 | 표 1개씩
  • ### 문제 N 안에 평가 항목을 체크리스트(- )로 나열
  • 특이사항은 > 특이사항: ... 으로 시작 — Claude가 채점에 반영
✕ 자주 하는 실수
  • 평가요소 이름을 약식으로 바꿈 (예: 함수 설계 및 구현 → 함수 설계)
  • 점수표만 적고 각 문제의 평가 항목을 안 적음
  • 같은 평가요소에 표가 두 개
💡 평가요소 이름 = 결과 표 컬럼명입니다.
여기 적은 글자가 그대로 채점 결과 표의 컬럼이 되니, 한 글자도 다르지 않게 통일해 주세요.

✓ 꼭 지킬 것
  • 파일명은 q1.py, q2.py... (소문자 q + 문제번호)
  • 학생들이 풀어야 하는 형식으로 작성 (input(), print() 사용)
  • 실행했을 때 테스트케이스 출력과 일치하는지 직접 한 번 돌려보기
• 업로드 방식
  • 여러 파일을 한꺼번에 올리려면 answer.zip 으로 압축해서 업로드 (zip 안 폴더 구조 자유)
  • 한 파일씩 추가 업로드도 가능
data/ 학생별 제출 코드. 폴더명의 숫자(_1, _2, ...)가 문제 번호에 대응 zip (학생이름(학번@dodam.hs.kr)/.../_N/Project/Main.py)

👩‍🎓 학생 코드 zip 작성 요령

zip 안 구조
data.zip
└── 홍길동(20106@dodam.hs.kr)/
    ├── q1/Project/Main.py
    ├── q2/Project/Main.py
    ├── ...
    └── q8/Project/Main.py
📌 도담 플랫폼에서 받은 zip을 그대로 올리면 끝입니다.
형식이 이미 위와 같이 되어 있어 별도 정리가 필요 없습니다.
✓ 폴더명 규칙
  • 학생 폴더: 이름(학번@dodam.hs.kr) 또는 학번만 (20106)
  • 문제 폴더: 폴더명에 숫자가 있으면 OK (q1, _1, 문제1 등)
  • 학생 코드 위치: <문제폴더>/Project/Main.py (도담 형식)
✕ 자주 하는 실수
  • 학생별로 zip을 따로 올림 — 모든 학생을 한 zip에 묶어야 함
  • 맥에서 zip 만들 때 생기는 __MACOSX 폴더 — 자동으로 무시되니 신경 안 써도 OK
• 미제출 처리
  • 학생 폴더에 특정 문제 폴더가 없거나 Main.py 가 비어 있으면 자동으로 "미제출(0점)"
